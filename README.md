# مدينة إجرائية AAA — Procedural City Forge

مشروع Three.js (r160) يولّد **مدينة منظّمة كاملة إجرائياً**: شبكة طرق هرمية، أحياء، مبانٍ متنوعة بخمسة طُرز معمارية، خامات PBR مولَّدة بالكامل بدقة تصل إلى 4K، نظام إضاءة نهار/ليل، ونظام **تهديم مبانٍ فيزيائي** بتكسير Voronoi.

> A fully procedural, high-detail and optimized city: organized road grid, 5 building styles, worker-generated 4K-capable PBR texture arrays with mask-based weathering, day/night lighting, and real-time Voronoi building destruction.

## التشغيل

```bash
pnpm install
pnpm dev        # http://localhost:5173
pnpm build      # dist/ — static, deploy anywhere
```

## الميزات

### المدينة الإجرائية
- شبكة منظمة: شارع رئيسي (Avenue 20m) كل ثالث طريق، شوارع 12m، أرصفة مرتفعة بحواف جرانيت وزوايا دائرية.
- أحياء حسب البعد عن المركز: **Downtown** (أبراج زجاجية بارتدادات + مكاتب)، **Midtown** (هوسماني + مكاتب)، **Residential** (طوب + هوسماني)، **Suburb** (منازل جصّ بأسقف قرميد) + حدائق.
- قطع أراضٍ على محيط البلوك تواجه الشارع، جدران مشتركة بلا نوافذ للمباني المتلاصقة.
- علامات طرق مهترئة (instanced)، أعمدة إنارة مع بقع ضوء ليلية، أشجار، سيارات متوقفة ومتحركة.

### المباني (5 طُرز)
- **هوسماني**: حجر جيري، قاعدة حجر خشن، أفاريز، إطارات نوافذ، شرفات حديدية متصلة، سقف زنك منسردي بنوافذ علوية ومداخن.
- **طوب**: عتبات وأعتاب خرسانية، مظلات محلات، خزانات مياه خشبية، وحدات تكييف.
- **مكاتب**: نوافذ شريطية، زعانف عمودية، أشرطة طوابق، غرفة معدات على السطح.
- **أبراج**: جدار ستائري (curtain wall) زجاجي عاكس، ارتدادات (setbacks)، هوائيات.
- **منازل**: جص ملوّن، مصاريع خشبية، سقف قرميد مائل.
- الزجاج يستخدم **Interior Mapping** (غرف وهمية بعمق، أثاث، ستائر) وتضيء الغرف ليلاً عشوائياً.

### الخامات (Masks + PBR)
- 15 طبقة: طوب، حجر جيري، حجر خشن، جص، خرسانة مسبقة، خرسانة مكسورة، حصى، قرميد، زنك، أسفلت، بلاط، جرانيت، عشب، معدن مطلي، خشب.
- كل طبقة مشتقة من **حقل ارتفاع بالأمتار**: Albedo + Height + Normal + Roughness + AO متطابقة تماماً، بلا حواف (seamless).
- دقة 512 / 1K / 2K / **4K** قابلة للاختيار (مع تقدير ذاكرة الرسوميات في الواجهة).
- أقنعة التجوية (Weathering masks) تُسقط في فضاء العالم: خطوط مطر، رذاذ أرضي، أوساخ في الشقوق حسب الارتفاع، طحالب، أوساخ الأسطح، تنويع ماكرو، ومعالجة ضد التكرار (anti-tiling).

### التهديم
- **صاروخ**: نقرة على أي مبنى/شارع → صاروخ → انفجار → المبنى يتحول إلى خلايا Voronoi (حتى 170 خلية) أصغر قرب الاصطدام.
- خلايا داخل نصف القطر تتفتت لشظايا وغبار، والقريبة تُدفع، ثم فحص إنشائي: كل ما لم يعد متصلاً بالأرض يسقط، وإذا فقد الطابق المصاب أكثر من 55% من خلاياه تنهار الطوابق فوقه.
- **انهيار تدريجي**: الكتل الساقطة بسرعة تكسر الخلايا الثابتة تحتها.
- **تفجير متحكَّم**: شحنات متتابعة في الطابق الأرضي ثم انهيار للداخل مع سحابة غبار.
- الواجهات الخارجية للحطام تحتفظ بالنوافذ (نفس شبكة النوافذ الإجرائية)، والوجوه الداخلية بخامة خرسانة مكسورة.

### الإضاءة
- دورة نهار/ليل كاملة (شمس، غروب ذهبي، قمر، نجوم، ضباب)، ظلال تتبع الكاميرا بلا اهتزاز (texel snapping).
- GI probe حي للانعكاسات، Contact AO مشتق من هندسة المدينة، SSAO، ارتداد لوني، Bloom، SMAA، تدرج ألوان.

## التحسين (Optimization)
- **مادة واحدة لكل المدينة**: كل الأسطح المعتمة تستخدم `DataArrayTexture` (طبقة لكل خامة) → عدد Draw calls صغير جداً.
- **LOD متدفق**: LOD1 (صناديق + نوافذ في الـshader) للمدينة كلها؛ LOD0 التفصيلي يُبنى للقطع القريبة فقط وبميزانية زمنية لكل إطار (بلا تقطيع) ويُحذف عند الابتعاد.
- مبانٍ تُدمج لكل قطعة (chunk = 2×2 بلوك)، وإخفاء المبنى المهدوم فوري عبر طيّ نطاق الفهارس (بلا إعادة بناء).
- Instancing للأشجار، الأعمدة، السيارات، العلامات، الشظايا، والغبار (billboards).
- الحطام المستقر يُدمج في mesh واحد (bake)؛ الأجسام تنام عند السكون.
- توليد الخامات في Worker pool مع Transferables، وتحرير نسخة CPU بعد رفعها للـGPU.
